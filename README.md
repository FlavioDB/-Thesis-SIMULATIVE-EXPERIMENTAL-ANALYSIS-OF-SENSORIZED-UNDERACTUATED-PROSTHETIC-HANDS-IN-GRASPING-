## Project Overview
This repository contains the MATLAB codebase, experimental data, and documentation developed for my Bachelor's Thesis in Foundation of Industrial Robotics. The project bridges the gap between hardware CAD design, software kinematic simulation, and real-world clinical validation.

Using the **MATLAB SynGrasp Toolbox**, a digital twin of the underactuated **Hannes prosthetic hand** was developed. The code translates raw CAD URDF data into Denavit-Hartenberg (DH) kinematic chains and features a custom algorithm to computationally simulate the hand's cable-driven differential mechanism. This allows the virtual digits to adaptively envelop objects of varying geometries. The simulated static equilibrium forces were then successfully validated against physical Force-Sensing Resistor (FSR) data collected during clinical trials at the INAIL Prosthetic Center.

## Repository Structure

### ⚙️ Core Simulation Engine
*   `simulate_hannes_grasp.m`: The primary workhorse function. It builds the kinematic hand model, spawns the target object, executes the adaptive differential closing loop with collision detection, and calculates grasp quality metrics (MEV, DTSC, GII) and static contact forces via the Jacobian pseudoinverse.
*   `HANNESHAND URDF.urdf`: The source CAD file used to extract the link dimensions and joint frames.
*   `ImportHannesHandURDF.m`: Preliminary script detailing the mathematical translation of URDF coordinates into DH parameters.

### 🚀 Automated Parameter Sweeps (Master Runners)
These scripts automate the data collection by running dozens of headless (no-graphics) simulations and exporting the results to Excel.
*   `Sphere_Master_Thesis_Runner.m`: Evaluates performance across 4 spherical radii and 3 spatial positions.
*   `Cylinder_Master_Thesis_Runner.m`: Evaluates performance across cylindrical objects, proving axial weaknesses.
*   `Prism_Master_Thesis_Runner.m`: Evaluates performance on sharp-edged objects (cubes/prisms).
*   `S_MATRIX_Master_Thesis_Runner.m`: Performs a sensitivity analysis by applying unbalanced and uniform synergy matrices to simulate internal transmission degradation.
*   `ProvaPolliceSMatrixEsperimentoLAR.m`: A parametric optimization sweep used to fine-tune the thumb's kinematic synergy coefficient to perfectly match physical FSR data collected in the LAR laboratory.

### 📊 Visualization & Development Scripts
*   `SphereThesisHannesDifferentialAdaptiveGrasping.m` (and Cylinder/Prism variants): Single-instance scripts with real-time 3D plotting enabled. Used for visual debugging and confirming grasp geometry.
*   `HannesHandStampaBene.m`: "Photoshoot" script designed to render high-quality, axis-free images of the hand mid-grasp with transparent backgrounds for the thesis and presentation.
*   `provapptgraficigrandi.m`: Data visualization script that generates thickened, large-font bar charts and line graphs specifically optimized for PowerPoint projector screens.
*   `Experiment1HannesHand.m` / `HannesHandEsperimentoLAR.m`: Initial exploratory scripts and setup validation.

### 📂 Data & Documentation
*   `Collected data/`: Contains all the `.xlsx` files generated by the Master Runner scripts (e.g., `Sphere_Grasp_Results.xlsx`, `LAR_Cylinder_Experiment.xlsx`).
*   `Report_Internship_FlavioDBorriello.docx`: Comprehensive report detailing the preliminary internship phase, SynGrasp setup, and clinical experiment preparation.
*   *(Note: The final thesis document and presentation slides are also included in this repository).*

## Requirements
*   **MATLAB** (Developed on R2024a/R2025b)
*   **SynGrasp Toolbox** (Version 2.6 or higher)

## How to Use
1. Ensure the SynGrasp library version 2.6 is added to your MATLAB path (with subfolders). (Refer to the "Report_Internship_FlavioDBorriello.docx" for installation procedure and some basic troubleshooting.)
2. Run any of the `_Master_Thesis_Runner.m` files to automatically generate simulation data and Excel tables.
3. To view the real-time 3D grasping animation, open `simulate_hannes_grasp.m` via one of the individual test scripts and ensure the `enable_plot` flag is set to `1`.
